# Огляд: приховування резервів + порядок як у «Дані»

**Дата:** 2026-05-17
**Файл:** `resources/views/admin/sites/show.blade.php` (вкладка Огляд), `public/assets/css/app.css`

## Проблема

Вкладка «Огляд» має 3 панелі:
- `_all` «Весь світ» (рядки ~298–478)
- `_raw` «Всі дані» (рядки ~479–614)
- per-ISO по країнах (рядки ~617–832)

Усі рендерять секції в порядку **Телефони → Месенджери → Адреси → Соцмережі → Ціни**.
Резерви (`standby_for_id` встановлено АБО `is_standby=true`) показуються інлайн із янтарним фоном — захаращують огляд.

Вкладка «Дані» (канонічна) використовує порядок **Телефони → Месенджери → Ціни → Соцмережі → Адреси** і вже згортає резерви під батьківським записом із лічильником (`$byParentPh`, `$sbCountsPh`).

## Вимоги

1. **Приховати резерви** в усіх 3 панелях. Біля основного запису, що має резерви, — бейдж `⬡ N резерв`. Клік → плаваючий popover зі списком резервних номерів/handle. Закриття: клік поза / Esc. Vanilla JS (CLAUDE.md: без JS-фреймворків).
2. **Порядок секцій** у всіх 3 панелях = як у «Дані»: **Телефони → Месенджери → Ціни → Соцмережі → Адреси**.
3. Усередині секції — активні (зелений фон `rgba(52,211,153,.18)`) першими. У `_all`/per-ISO tier-сортування є; додати аналог у `_raw`.

## Дизайн

### Групування резервів (спільний `@php`-хелпер)
Для кожного типу (phones, socials):
- `primaries` = записи без `standby_for_id` і без `is_standby`
- `reservesByParent` = записи з `standby_for_id` ∈ primary.id, згруповані за `standby_for_id`
- `reservesPool` = резерви без відомого батька (pool/orphans)

Основний список рендерить лише `primaries`. Для primary з резервами — бейдж із попапом. `reservesPool` → один бейдж рівня секції `Резерви: N`.

### Popover (vanilla JS + CSS)
- Бейдж: `<button class="rsv-badge" onclick="toggleRsvPop(event,'rsv-<uid>')">`.
- Popover: `<div class="rsv-pop" id="rsv-<uid>">…список…</div>`, `position:absolute`, прихований за замовч.
- Одна глобальна функція `toggleRsvPop(e,id)` + слухач `document` на клік-поза та Esc для закриття всіх `.rsv-pop`.
- CSS-класи `.rsv-badge`, `.rsv-pop` додати в `app.css`.

### Порядок
Переставити блоки `@if($xPhs->count())…` у трьох панелях у послідовність Телефони → Месенджери → Ціни → Соцмережі → Адреси. У `_raw` додати tier-сортування (активні першими) аналогічно `$wSort`/`$mSortPh`.

### Обсяг ризику
Зберігаю окрему table-розмітку кожної панелі (різні колонки: `_raw`=5, інші=3). Спільне лише: групувальний хелпер, JS-функція, CSS. Без рефакторингу розмітки.

## Аудит проєкту (після фічі)
Read-only огляд: безпека (4 sec-коміти в `feature/security-bulk-auth` — оцінити чи потрібні), коректність, мертвий код, untracked-сміття (`nul`, `public/demo.html`), розмір `show.blade.php` (~2800 рядків). Втілити розумні покращення за пріоритетом; коміт + пуш.
